# 테스트 봇

게임(index.html)을 고치지 않고 헤드리스 브라우저에서 그대로 띄운 뒤, 봇이 사람처럼 입력(이동 조이스틱·스킬 버튼·물약·구르기)만 넣어 플레이합니다. 체력·마나·물약·몹 생성·맵 사건·보스 패턴은 실제 게임과 같습니다.

## 준비

```
cd tools/bot
npm install          # puppeteer-core, three@0.128
```

Chrome 경로가 다르면 `CHROME=/경로/chrome` 를 붙입니다.

## 실행

```
node run.js --cls warrior:whirl,mage:chainl --ch 8 --seeds 3 --par 4 --out ch8
node report.js out/ch8.json
```

| 옵션 | 뜻 | 기본 |
|---|---|---|
| `--cls` | `직업:주력 스킬`, 쉼표로 여러 개 | `warrior:whirl` |
| `--ch` | 스토리 장 (1~10) | 8 |
| `--lv --tier --enh` | 레벨·장비 티어·강화 (비우면 장별 기본값 `SPEC`) | |
| `--q` | 장비 옵션 품질 0~1 | 0.5 |
| `--skill` | 봇 실력 `good` / `normal` / `poor` | normal |
| `--seeds` | 시드 개수 (같은 시드 = 같은 무작위 결과) | 3 |
| `--max` | 한 판 최대 게임 시간(초) | 900 |
| `--par` | 동시에 돌릴 판 수 | 3 |
| `--debug 1` | 3초마다 봇 상태 기록 | |

## 캠페인 (1장부터 10장까지 이어서)

```
node camp.js --cls warrior:whirl,mage:chainl --seeds 2 --par 4 --out camp1
node camp-sum.js out/camp1.json      # 스킬별 요약
node camp-report.js out/camp1.json   # 장별 상세 표
```

새 캐릭터(튜토리얼을 마친 레벨 3, 시작 장비)로 1장부터 진행합니다. 진행 중 5초마다 게임의 자동 장착으로 더 좋은 장비를 끼고, 장을 마칠 때마다 남은 골드로 강화(가장 낮은 부위부터, 같으면 무기 먼저)합니다. 장별 클리어 시간·보스 시간·사망·최저 체력·레벨·골드 수입·강화·장비 티어·DPS·EHP를 기록합니다. `--to 7` 처럼 끝 장을 정할 수 있습니다.

## 봇이 하는 일

- 길찾기: 맵을 0.5m 격자로 나눠 벽·바리케이드를 피해 최단 경로로 이동
- 목표: 다음 벽 앞에서 해야 할 일(도르래·봉화, 불씨 옮기기, 자리 지키기, 둥지, 수호자, 바리케이드, 열쇠지기)을 먼저 하고 없으면 길 끝 제단
- 전투: 근접 스킬은 붙고 원거리 스킬은 거리 유지, 벽 너머 적은 무시
- 회피: 빨간 원 장판 밖으로, 날아오는 투사체는 옆으로 비키거나 구르기
- 물약: 체력·마나가 기준 아래로 내려가면 사용

## 기록하는 것

클리어 여부·시간, 보스 처치 시간, 사망 횟수, 최저 체력, 받은 피해와 출처, 물약 사용, 처치 수, 실제 DPS, 골드·레벨 변화
